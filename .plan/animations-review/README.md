# Animations Review

Created: 2026-05-26

This folder contains the motion-language review for the public website. The
review focuses on what animation communicates to users, where motion is missing,
and how to make interaction feel coherent without making every element behave
the same way.

## Documents

- [HTML presentation](./presentation.html) - slide deck summarizing the review,
  motion-language findings, and implementation recommendations.
- [Implementation tasks](./TASKS.md) - prioritized backlog for turning the
  recommendations into code changes; canonical task specs live in
  [E002 — Animation Language](../epics/E002-2026-05-26-animation-language/PLAN.md).
- [Motion language review](./MOTION-LANGUAGE-REVIEW.md) - current-state audit,
  communication intent, consistency gaps, and user-facing interpretation.
- [Animation recommendations](./RECOMMENDATIONS.md) - prioritized motion
  backlog with concrete animation proposals and implementation notes.
